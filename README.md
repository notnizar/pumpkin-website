# Pumpkin Group — Agency Website

Bilingual (English / Arabic) marketing site for **Pumpkin Group LLC**, a branding, marketing, advertising and digital agency based in Khilda, Amman, Jordan.

**Live site:** https://notnizar.github.io/pumpkin-website/

**Preview artifact:** https://claude.ai/artifact/SymUDGcwCajvjDa71KvuWt

## Features

- **English and Arabic** with a one-tap language switch. Arabic mode flips to right-to-left, swaps to Arabic typefaces (Cairo + IBM Plex Sans Arabic) and mirrors icons.
- **Three.js hero**: a particle pumpkin (~6k points, 10 ribs, stem, orbit ring and dust) that rotates, breathes and follows the mouse on desktop. Colors follow the site theme.
- **Light and dark themes** with a toggle; follows the visitor's system setting by default.
- **Selected work from Behance**: six real projects from [behance.net/PumpkinGroup](https://www.behance.net/PumpkinGroup) (DAMITCI, Smokey Burger, Shaban, Angelina’s Oven, Issa Ayyad Auto Trading, Uncle Osaka). Each tile shows the project's Behance cover, uncropped, over a soft blurred field in the cover's own colours, and opens the project's Behance gallery.
- **Its own phone design**: a floating dock with a scroll-progress ring, the current section's name and a CTA that folds away at Contact; a bottom-sheet menu you can swipe closed; a centred hero whose pumpkin you can swipe to spin and tap to burst; service cards that stack as you scroll; a process rail; a 3D work carousel with page dots that peeks at the next project; masked heading reveals; press and ripple feedback on touch. 44px+ tap targets, no horizontal scroll.
- **Motion**: a brand preloader on the first visit of a session, then the headline words rise out of masks while the pumpkin assembles from a scattered cloud. The pumpkin parts around the cursor, bursts and wobbles back when clicked, and dissolves back into particles as you scroll past it. Scroll reveals with stagger on every section, a process line that fills as you read, a quote that lights up word by word, a scroll-aware marquee, cursor-tilt service cards with a spotlight, drifting work-tile art with parallax, magnetic buttons, a custom cursor on laptops (a dot and a springy ring that wraps buttons, turns into a "View" disc over projects and a "Burst" ring over the pumpkin, and sheds pumpkin seeds when you move fast or click), film grain, a nav that hides on scroll-down, a progress bar, and a circular theme wipe (View Transitions). All of it is gated behind `html.anim`, so visitors with reduced motion, no JavaScript or an old browser get the finished page at once.
- **Performance**: pixel ratio capped at 1.5, fewer particles on phones, render loop pauses when the hero is off screen or the tab is hidden, `content-visibility: auto` on below-the-fold sections, Three.js loaded deferred from cdnjs, reduced-motion respected.
- Single self-contained HTML file. No build step.

## Files

| File | Purpose |
|---|---|
| `index.html` | Complete standalone page. Served by GitHub Pages. |
| `artifact.html` | Same page without the `<html>/<head>/<body>` skeleton, for the Claude artifact host. Generated by `python3 scripts/build-artifact.py`. |
| `scripts/build-artifact.py` | Derives `artifact.html` from `index.html`. |
| `scripts/work-backdrop.py` | Makes the blurred backdrop for a Selected work cover (needs Pillow). |
| `assets/` | Favicon (SVG and PNG), Apple touch icon, Open Graph image, and the two HTML sources they are rendered from. |
| `assets/work/` | Selected work covers from Behance and their blurred backdrops. |
| `.github/workflows/pages.yml` | Deploys the repo root to GitHub Pages on every push to `main`. |

## Run locally

Open `index.html` in any browser, or serve the folder:

```bash
npx serve .
```

Then visit `http://localhost:3000`.

## Deploy

Any static host works (GitHub Pages, Netlify, Vercel, Cloudflare Pages). This repo deploys to GitHub Pages through the workflow in `.github/workflows/pages.yml` on every push to `main`.
